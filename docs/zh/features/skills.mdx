---
title: "通过 MCP 发布技能"
description: "在 MCPHub 端点导入和发布包含多个文件的 Agent Skills。"
---

管理员可以通过 MCPHub 使用 [MCP Skills 扩展](https://skills.extensions.modelcontextprotocol.io/specification/beta/skills)发布 [Agent Skills](https://agentskills.io/specification)。远程发现和加载需要支持该扩展及 MCP 2026-07-28 的客户端。客户端通过 MCP 读取技能，MCPHub 不会将文件安装到智能体所在的本地环境。

## 导入和发布

1. 以管理员身份打开仪表盘中的**技能**页面，默认显示**已安装**。
2. 点击**手动导入**，在弹窗中选择包含 `SKILL.md` 的本地文件夹，或输入公开 GitHub 文件夹或 skills.sh 技能链接。切换到**发现**会自动加载 skills.sh 累计安装榜的前 20 项，也可以搜索并选择技能导入。
3. 勾选**启用**并指定发布范围。勾选**全局端点**后，启用了全局路由的 `/mcp` 可以发现该技能。所选分组的端点沿用现有路由认证和分组可见性。
4. 将兼容的客户端接入发布端点。客户端通过 `skills/list` 发现技能、通过 `skills/get` 获取清单、通过 `resources/read` 读取文件。

在**技能 → 配置**中选择远程导入和替换所用的连接方式。默认复用服务端的 `HTTPS_PROXY` 或 `HTTP_PROXY` 并遵循 `NO_PROXY`，两者均未配置时直接连接。也可以指定直接连接，或手动填写 HTTP(S) 代理地址。发现列表和搜索沿用服务端默认的网络配置。

发现功能使用 skills.sh 的公开目录接口，支持来源为公开 GitHub 仓库的技能。导入时从仓库默认分支定位技能，并固定到当时的提交。若有多个匹配目录，请输入具体的 GitHub 文件夹 URL，例如 `https://github.com/owner/repo/tree/main/skill-name`。也可以使用提交 SHA，或对分支和标签名中的斜杠进行 URL 编码。

目录名必须与 `SKILL.md` 中的 `name` 一致，并且在技能目录中唯一。每项技能支持最多 512 个普通文件，文件总大小不超过 16 MiB。GitHub 来源在导入时固定到一个提交。使用**替换文件**更新已有技能，保留技能 ID、URI 和发布范围。取消**启用**或删除技能即可撤下发布内容。

使用 TypeScript SDK 时，创建客户端时指定 `versionNegotiation: { mode: "auto" }`，以发现 2026-07-28 端点。

## 存储与兼容性

每项技能保存在 MCPHub 工作目录下的 `data/skills/<技能名>/`。目录中包含原始的 `SKILL.md`、按原相对路径保存的附件，以及保留给 MCPHub 的元数据文件 `.mcphub.json`。请通过**替换文件**更新内容并重新生成摘要。备份时请包含 `data/skills/`。Docker 部署时挂载 `/app/data` 以持久化这些目录。单实例自托管部署支持两种设置后端。

首次访问技能目录时，MCPHub 会迁移 `data/skills/` 和 `<设置文件>.skills/` 中的预览版 JSON 快照，保留 ID 和发布设置。有同名快照时，已有目录或第一个迁移的快照保留该名称，其余快照以 `.conflict` 文件保留在原目录，供手动恢复。

文件清单和 SHA-256 摘要对应原始 UTF-8 或二进制字节。如果技能在获取清单后更新，客户端可刷新清单并校验新文件。原有工具、提示词和资源继续通过各自的服务方法访问。

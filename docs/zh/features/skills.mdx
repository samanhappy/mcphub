---
title: "通过 MCP 发布技能"
description: "在 MCPHub 端点导入和发布包含多个文件的 Agent Skills。"
---

管理员可以通过 MCPHub 使用 [MCP Skills 扩展](https://skills.extensions.modelcontextprotocol.io/specification/beta/skills)发布 [Agent Skills](https://agentskills.io/specification)。远程发现和加载需要支持该扩展及 MCP 2026-07-28 的客户端。客户端通过 MCP 读取技能，MCPHub 不会将文件安装到智能体所在的本地环境。

## 导入和发布

1. 以管理员身份打开仪表盘中的**技能**页面。
2. 选择包含 `SKILL.md` 的本地文件夹，或输入公开 GitHub 文件夹 URL，例如 `https://github.com/owner/repo/tree/main/skill-name`。分支或标签名包含斜杠时，请使用提交 SHA 或对斜杠进行 URL 编码。
3. 勾选**启用**并指定发布范围。勾选**全局端点**后，启用了全局路由的 `/mcp` 可以发现该技能。所选分组的端点沿用现有路由认证和分组可见性。
4. 将兼容的客户端接入发布端点。客户端通过 `skills/list` 发现技能、通过 `skills/get` 获取清单、通过 `resources/read` 读取文件。

目录名必须与 `SKILL.md` 中的 `name` 一致。每项技能支持最多 512 个普通文件，文件总大小不超过 16 MiB。GitHub 来源在导入时固定到一个提交。使用**替换文件**更新快照，保留技能 URI 和发布范围。取消**启用**或删除技能即可撤下发布内容。

使用 TypeScript SDK 时，创建客户端时指定 `versionNegotiation: { mode: "auto" }`，以发现 2026-07-28 端点。

## 存储与兼容性

快照保存在设置文件旁的 `.skills` 附属目录中。备份时请包含该目录，Docker 部署时请挂载其父目录以持久化。单实例自托管部署可以使用此功能，支持文件和数据库两种设置后端。

文件清单和 SHA-256 摘要对应原始 UTF-8 或二进制字节。如果技能在获取清单后更新，客户端可刷新清单并校验新文件。原有工具、提示词和资源继续通过各自的服务方法访问。

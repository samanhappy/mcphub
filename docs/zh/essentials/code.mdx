## 内联代码

要表示内联代码块，请用反引号 `` ` `` 包围文本。

```md
在此文本中，`console.log('hello');` 是内联代码。
```

在此文本中，`console.log('hello');` 是内联代码。

## 代码块

您可以创建代码块以显示多行代码。这些代码块也支持语法高亮显示。

```javascript
console.log('Hello World');
```

### 使用三个反引号

````md
```javascript
console.log('Hello World');
```
````

### 语法高亮

我们使用 [Prism](https://prismjs.com/) 来语法高亮显示。Prism 支持 [各种编程语言](https://prismjs.com/#supported-languages)。

要添加语法高亮显示，请在代码块的第一行指定语言。

````md
```python
def hello():
    print("Hello World")
```
````

```python
def hello():
    print("Hello World")
```

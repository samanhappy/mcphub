## 标题

最佳实践是在一页中只使用一个 `#` 标题，它会自动成为该页面的标题。

```md
# 标题 1

## 标题 2

### 标题 3

#### 标题 4

##### 标题 5

###### 标题 6
```

<ResponseExample>

# 标题 1

## 标题 2

### 标题 3

#### 标题 4

##### 标题 5

###### 标题 6

</ResponseExample>

## 文本格式

我们支持大多数标准的 markdown 格式。我们还支持 **粗体**、_斜体_、下划线以及 ~~删除线~~。

```md
**粗体**、_斜体_、下划线，以及 ~~删除线~~
```

您还可以使用 `highlight()` 函数来<mark>高亮显示文本</mark>。

```md
您还可以使用 `highlight()` 函数来<mark>高亮显示文本</mark>。
```

## 链接

您可以添加到其他页面和外部链接的链接。

```md
[Mintlify](https://mintlify.com)
```

链接到页面通过使用您在页面开头的 frontmatter 中设置的文件名或 `title`。

```md
[快速开始](/zh/quickstart)
```

## 图片

![Hero Light](/images/hero-light.png)

```md
![Hero Light](/images/hero-light.png)
```

<Tip>

**使用图片时的最佳实践**

尝试保持图片在 1000px 宽度以下。通常，图片可能会在移动设备上变得太小或像素化。

</Tip>

这些端点只操作当前认证主体。API 不接受用户名参数，管理员也不能通过这些
端点读取其他用户的值。所有操作都会先检查服务器可见性和
`server.invoke` 权限。

### 列出凭据绑定

`GET /api/credentials` 仅返回模板元数据、是否完整、各字段是否已配置以及
更新时间；不会返回原始值或加密载荷。

### 保存凭据绑定

`PUT /api/credentials/:serverName` 的请求体如下：

```json
{
  "values": {
    "env": { "SEARCH_API_KEY": "user-secret" },
    "headers": { "Authorization": "Bearer user-secret" }
  }
}
```

首次写入必须提供所有必填字段；已有绑定可以只轮换部分字段。下一次工具
调用会使用新值，并仅重启该用户在该服务器上的 stdio 进程。

### 删除凭据绑定

`DELETE /api/credentials/:serverName` 只删除当前用户的绑定，并只关闭该用户
对应的运行时。后续调用会提示用户前往“我的凭据”重新配置。

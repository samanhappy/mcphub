<Info>
  **前提条件**：请在继续之前安装 Node.js（版本 19 或更高）。
  <br />
  请在继续之前升级到 ```docs.json```，并删除旧的 ```mint.json``` 文件。
</Info>

按照以下步骤在您的操作系统上安装和运行 Mintlify：

**步骤 1**：安装 Mintlify：

<CodeGroup>

```bash npm
npm i -g mintlify
```

```bash yarn
yarn global add mintlify
```

</CodeGroup>

**步骤 2**：导航到文档目录（`docs.json` 文件所在的位置）并执行以下命令：

```bash
mintlify dev
```

您的文档的本地预览将在 `http://localhost:3000` 可用。

### 自定义端口

默认情况下，Mintlify 使用端口 3000。您可以使用 `--port` 标志自定义 Mintlify 运行的端口。例如，要在端口 3333 上运行 Mintlify，请使用此命令：

```bash
mintlify dev --port 3333
```

如果您尝试在已在使用的端口上运行 Mintlify，它将使用下一个可用端口：

```md
端口 3000 已在使用中。尝试使用 3001。
```

## Mintlify 版本

请注意，每个 CLI 版本都与特定版本的 Mintlify 相关联。如果您的本地网站与生产版本不一致，请更新 CLI：

<CodeGroup>

```bash npm
npm i -g mintlify@latest
```

```bash yarn
yarn global upgrade mintlify
```

</CodeGroup>

## 验证链接

CLI 可以帮助验证文档中的引用链接。要识别任何损坏的链接，请使用以下命令：

```bash
mintlify broken-links
```

## 部署

<Tip>
  Mintlify 通过我们的 GitHub 应用实现持续部署。安装后，推送到您的默认分支将自动更新您的文档。
</Tip>

### GitHub 集成

我们强烈建议部署使用我们的 [GitHub 集成](https://github.com/apps/mintlify)，该集成在有人将更改推送到您的存储库时自动部署更改。只需安装 GitHub 应用到您的存储库并推送到您的默认分支！安装链接可以在您的 [仪表板](https://dashboard.mintlify.com) 中找到。

#### 故障排除

- Mintlify dev 无法运行 - 运行 `mintlify install` 它将重新安装依赖项。
- 页面加载为 404 - 确保您在包含 `docs.json` 的文件夹中运行

## 代码格式化

我们已经内置了对自动代码格式化的支持！我们使用 [Prettier](https://prettier.io/) 来格式化文件。

# MCPHub'a Hos Geldiniz

MCPHub, birden fazla MCP (Model Context Protocol) sunucusunu esnek Streamable HTTP (SSE) uclari altinda organize ederek yonetmeyi ve olceklendirmeyi kolaylastirir; tum sunuculara, tekil sunuculara veya mantiksal sunucu gruplarina erisimi destekler.

## Hizli Baslangic

Docker ile MCPHub'i dakikalar icinde calistirin:

```bash
docker run -p 3000:3000 ghcr.io/vaur94/mcphub
```

Veya ozel yapilandirma ile:

```bash
docker run -p 3000:3000 -v $(pwd)/mcp_settings.json:/app/mcp_settings.json ghcr.io/vaur94/mcphub
```

Panoya `http://localhost:3000` adresinden erisin ve varsayilan bilgilerle giris yapin:

- Username: `admin`
- Password: `admin123`

## Temel Kavramlar

### MCP Uclari

MCPHub, MCP sunuculariniza erismek icin birden fazla yol saglar:

- **Birlesik Erisim**: `http://localhost:3000/mcp` - Tum sunuculara erisim
- **Grup Erisimi**: `http://localhost:3000/mcp/{group}` - Belirli gruplara erisim
- **Sunucu Erisimi**: `http://localhost:3000/mcp/{server}` - Tekil sunuculara erisim
- **Akilli Yonlendirme**: `http://localhost:3000/mcp/$smart` - AI destekli arac kesfi

### Protokol Destegi

- **HTTP MCP**: Modern streamable HTTP arayuzu (onerilen)
- **SSE**: Geriye donuk uyumluluk icin Server-Sent Events
- **stdio**: Sunucu iletisiminde yerel MCP protokolu

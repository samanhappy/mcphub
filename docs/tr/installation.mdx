## On Kosullar

MCPHub'i kurmadan once su gereksinimlerin mevcut oldugundan emin olun:

- **Node.js** 18+ (yerel gelistirme icin)
- **Docker** (production icin onerilir)
- **pnpm** (yerel gelistirme icin)

Akilli Yonlendirme icin (opsiyonel):

- **pgvector eklentili PostgreSQL**
- **LLM Saglayicisi (OpenAI veya uyumlu) API Key**

## Kurulum Yontemleri

<Tabs>
  <Tab title="Docker (Onerilen)">
    ### Docker ile Kurulum

    Docker, MCPHub'i production ortaminda yayinlamanin onerilen yoludur.

    #### 1. Temel Kurulum

    ```bash
    # Pull the latest image
    docker pull ghcr.io/vaur94/mcphub:latest

    # Run with default settings
    docker run -d \
      --name mcphub \
      -p 3000:3000 \
      ghcr.io/vaur94/mcphub:latest
    ```

    #### 2. Ozel Yapilandirma ile

    ```bash
    # Create your configuration file
    cat > mcp_settings.json << 'EOF'
    {
      "mcpServers": {
        "fetch": {
          "command": "uvx",
          "args": ["mcp-server-fetch"]
        },
        "playwright": {
          "command": "npx",
          "args": ["@playwright/mcp@latest", "--headless"]
        }
      }
    }
    EOF

    # Run with mounted config
    docker run -d \
      --name mcphub \
      -p 3000:3000 \
      -v $(pwd)/mcp_settings.json:/app/mcp_settings.json \
      ghcr.io/vaur94/mcphub:latest
    ```

    #### 3. Ortam Degiskenleri ile

    ```bash
    docker run -d \
      --name mcphub \
      -p 3000:3000 \
      -e PORT=3000 \
      -e BASE_PATH="" \
      ghcr.io/vaur94/mcphub:latest
    ```

    #### 4. Docker Compose

    Bir `docker-compose.yml` dosyasi olusturun:

    ```yaml
    version: '3.8'
    services:
      mcphub:
        image: ghcr.io/vaur94/mcphub:latest
        ports:
          - "3000:3000"
        volumes:
          - ./mcp_settings.json:/app/mcp_settings.json
        environment:
          - PORT=3000
          - BASE_PATH=""
          - REQUEST_TIMEOUT=60000
        restart: unless-stopped

      # Optional: PostgreSQL for Smart Routing
      postgres:
        image: pgvector/pgvector:pg17
        environment:
          POSTGRES_DB: mcphub
          POSTGRES_USER: mcphub
          POSTGRES_PASSWORD: mcphub_password
        volumes:
          - postgres_data:/var/lib/postgresql/data
        ports:
          - "5432:5432"

    volumes:
      postgres_data:
    ```

    Su komutla calistirin:

    ```bash
    docker-compose up -d
    ```

  </Tab>

  <Tab title="npm Paketi">
    ### npm Paketi ile Kurulum

    MCPHub'i global bir npm paketi olarak kurun:

    #### 1. Global Kurulum

    ```bash
    # Install globally
    npm install -g @vaur94/mcphub

    # Or with yarn
    yarn global add @vaur94/mcphub

    # Or with pnpm
    pnpm add -g @vaur94/mcphub
    ```

    #### 2. MCPHub'i Calistirma

    ```bash
    # Run with default settings
    mcphub

    # Run with custom port
    PORT=8080 mcphub
    ```

  </Tab>

  <Tab title="Yerel Gelistirme">
    ### Yerel Gelistirme Kurulumu

    Gelistirme, ozellestirme veya katkida bulunmak icin:

    #### 1. Depoyu Klonlayin

    ```bash
    # Clone the repository
    git clone https://github.com/vaur94/mcphub.git
    cd mcphub
    ```

    #### 2. Bagimliliklari Kurun

    ```bash
    # Install dependencies with pnpm (recommended)
    pnpm install

    # Or with npm
    npm install

    # Or with yarn
    yarn install
    ```

    #### 3. Gelistirme Modu

    ```bash
    # Start both backend and frontend in development mode
    pnpm dev

    # This will start:
    # - Backend on http://localhost:3001
    # - Frontend on http://localhost:5173
    # - Frontend proxies API calls to backend
    ```

    #### 4. Production Icin Build

    ```bash
    # Build both backend and frontend
    pnpm build

    # Start production server
    pnpm start
    ```

    #### 5. Gelistirme Scriptleri

    ```bash
    # Backend only (for API development)
    pnpm backend:dev

    # Frontend only (when backend is running separately)
    pnpm frontend:dev

    # Run tests
    pnpm test

    # Lint code
    pnpm lint

    # Format code
    pnpm format
    ```

    <Note>
      Windows'ta backend ve frontend'i ayri ayri calistirmaniz gerekebilir:
      ```bash
      # Terminal 1: Backend
      pnpm backend:dev

      # Terminal 2: Frontend
      pnpm frontend:dev
      ```
    </Note>

  </Tab>

  <Tab title="Kubernetes">
    ### Kubernetes ile Yayinlama

    MCPHub'i Kubernetes uzerinde bu manifestlerle yayinlayin:

    #### 1. Settings icin ConfigMap

    ```yaml
    apiVersion: v1
    kind: ConfigMap
    metadata:
      name: mcphub-config
    data:
      mcp_settings.json: |
        {
          "mcpServers": {
            "fetch": {
              "command": "uvx",
              "args": ["mcp-server-fetch"]
            },
            "playwright": {
              "command": "npx",
              "args": ["@playwright/mcp@latest", "--headless"]
            }
          }
        }
    ```

    #### 2. Deployment

    ```yaml
    apiVersion: apps/v1
    kind: Deployment
    metadata:
      name: mcphub
    spec:
      replicas: 1
      selector:
        matchLabels:
          app: mcphub
      template:
        metadata:
          labels:
            app: mcphub
        spec:
          initContainers:
            - name: prepare-config
              image: busybox:1.28
              command:
                [
                  "sh",
                  "-c",
                  "cp /config-ro/mcp_settings.json /etc/mcphub/mcp_settings.json",
                ]
              volumeMounts:
                - name: config
                  mountPath: /config-ro
                  readOnly: true
                - name: app-storage
                  mountPath: /etc/mcphub
          containers:
            - name: mcphub
              image: ghcr.io/vaur94/mcphub:latest
              ports:
                - containerPort: 3000
              resources:
                requests:
                  cpu: 100m
                  memory: 128Mi
                limits:
                  cpu: 500m
                  memory: 512Mi
              env:
                - name: PORT
                  value: "3000"
                - name: MCPHUB_SETTING_PATH
                  value: /etc/mcphub/mcp_settings.json
              volumeMounts:
                - name: app-storage
                  mountPath: /etc/mcphub
          volumes:
            - name: config
              configMap:
                name: mcphub-config
            - name: app-storage
              emptyDir: {}
    ```

    #### 3. Service

    ```yaml
    apiVersion: v1
    kind: Service
    metadata:
      name: mcphub-service
    spec:
      selector:
        app: mcphub
      ports:
      - port: 80
        targetPort: 3000
      type: ClusterIP
    ```

    #### 4. Ingress (Opsiyonel)

    ```yaml
    apiVersion: networking.k8s.io/v1
    kind: Ingress
    metadata:
      name: mcphub-ingress
      annotations:
        nginx.ingress.kubernetes.io/proxy-buffering: "off"
    spec:
      rules:
      - host: mcphub.yourdomain.com
        http:
          paths:
          - path: /
            pathType: Prefix
            backend:
              service:
                name: mcphub-service
                port:
                  number: 80
    ```

    Su komutlarla yayinlayin:

    ```bash
    kubectl apply -f mcphub-configmap.yaml
    kubectl apply -f mcphub-deployment.yaml
    kubectl apply -f mcphub-service.yaml
    kubectl apply -f mcphub-ingress.yaml
    ```

</Tabs>

## Akilli Yonlendirme Kurulumu (Opsiyonel)

Akilli Yonlendirme, vektor semantik arama ile AI destekli arac kesfi saglar.

### Gereksinimler

1. **pgvector eklentili PostgreSQL**
2. **LLM Saglayicisi (OpenAI veya uyumlu) API Key**

### Veritabani Kurulumu

<Tabs>
  <Tab title="Docker PostgreSQL">
    ```bash
    # Run PostgreSQL with pgvector
    docker run -d \
      --name mcphub-postgres \
      -e POSTGRES_DB=mcphub \
      -e POSTGRES_USER=mcphub \
      -e POSTGRES_PASSWORD=your_password \
      -p 5432:5432 \
      pgvector/pgvector:pg16
    ```
  </Tab>

  <Tab title="Mevcut PostgreSQL">
    Mevcut bir PostgreSQL orneginiz varsa:

    ```sql
    -- Connect to your PostgreSQL instance
    -- Create database
    CREATE DATABASE mcphub;

    -- Connect to the mcphub database
    \c mcphub;

    -- Enable pgvector extension
    CREATE EXTENSION IF NOT EXISTS vector;
    ```

  </Tab>

  <Tab title="Bulut PostgreSQL">
    Bulut saglayicilari (AWS RDS, Google Cloud SQL, vb.) icin:

    1. Bulut konsolunda pgvector eklentisini etkinlestirin
    2. `mcphub` isimli bir veritabani olusturun
    3. Baglanti bilgilerini not alin

  </Tab>
</Tabs>

## Dogrulama

Kurulumdan sonra MCPHub'in calistigini dogrulayin:

### Pano Erisimi

Tarayicinizda su adrese gidin:

```
http://localhost:3000
```

## Sorun Giderme

<AccordionGroup>
  <Accordion title="Docker Sorunlari">
    **Port already in use:**
    ```bash
    # Check what's using port 3000
    lsof -i :3000

    # Use a different port
    docker run -p 8080:3000 ghcr.io/vaur94/mcphub
    ```

    **Container won't start:**
    ```bash
    # Check container logs
    docker logs mcphub

    # Run interactively for debugging
    docker run -it --rm ghcr.io/vaur94/mcphub /bin/bash
    ```

  </Accordion>

  <Accordion title="npm Kurulum Sorunlari">
    **Permission errors:**
    ```bash
    # Use npx instead of global install
    npx @vaur94/mcphub

    # Or fix npm permissions
    npm config set prefix ~/.npm-global
    export PATH=~/.npm-global/bin:$PATH
    ```

    **Node version issues:**
    ```bash
    # Check Node version
    node --version

    # Install Node 18+ using nvm
    nvm install 18
    nvm use 18
    ```

  </Accordion>

  <Accordion title="Ag Sorunlari">
    **Pano'ya erisemiyorum:**
    - MCPHub'in calistigini kontrol edin: `ps aux | grep mcphub`
    - Port baglantisini dogrulayin: `netstat -tlnp | grep 3000`
    - Guvenlik duvari ayarlarini kontrol edin
    - `localhost:3000` yerine `127.0.0.1:3000` deneyin

    **AI istemcileri baglanamiyor:**
    - Uc nokta URL'sinin dogru oldugundan emin olun
    - MCPHub'in bir proxy arkasinda olup olmadigini kontrol edin
    - Kubernetes/Docker ortaminda ag politikalarini dogrulayin

  </Accordion>

  <Accordion title="Akilli Yonlendirme Sorunlari">
    **Database connection failed:**
    ```bash
    # Test database connection
    psql $DB_URL -c "SELECT 1;"

    # Check if pgvector is installed
    psql $DB_URL -c "CREATE EXTENSION IF NOT EXISTS vector;"
    ```

    **Embedding service errors:**
    - LLM saglayicisi API key'in gecerli oldugunu dogrulayin
    - Internet baglantisini kontrol edin
    - Rate limit'leri izleyin

  </Accordion>
</AccordionGroup>
